# MC Panel web client

React, TypeScript, Vite, and shadcn/ui frontend for MC Panel. The production
build is bundled into `McPanel.Api` and served from the same origin as the API.

```bash
npm ci
npm run typecheck
npm run lint
npm test
npm run build
```

See the repository-level `README.md` for the supported same-origin local run,
complete build instructions, and deployment guidance.
